Install a role

Provisions a fully-configured server stack on any enrolled agent in one click. To install on this reevectl server itself, enroll it as an agent first (run install.sh on this host with an enrollment token).

Authentication Server

Stands up a Samba 4 Active Directory Domain Controller with Kerberos and DNS. The host's resolver and services will be reconfigured.

Print Server (CUPS)

Installs CUPS and starts cups.service. By default the admin UI is restricted to localhost.

Security Server

The lab/branch-office "everything box": DHCP + DNS (dnsmasq), Pi-hole-style domain blocklists for ads + malware, Squid forward proxy, a local Ubuntu apt mirror so the fleet doesn't all hit the internet, a ClamAV signature mirror, and a central rsyslog endpoint. The apt mirror initial sync runs in the background and may consume 50–200 GB of disk and several hours.
